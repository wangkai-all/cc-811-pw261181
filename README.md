# 县域比率分层估计与总量校准

针对"区县样本量差异大、小县比率剧烈波动、简单合并又抹掉差异"的问题，
本应用用**虚构**抽样数据演示一套完整方案：

1. **分层经验贝叶斯模型**估计各县比率与区间 —— 小样本县自动向模型收缩，
   收缩强度 τ² 从训练数据估计（**不把人口量当样本量**，人口只在校准阶段作总量权重）；
2. **总量校准**把县级估计与不确定性一起调整，精确匹配全市确认总量，
   保留非负与上限约束；全市总量与县级已确认项冲突时**报告不可行，绝不暗改确认数据**；
3. **零样本县**明确标记为模型外推；**样本设计权重**经 Kish 有效样本量进入估计与验证；
4. **整地区留出验证**检验模型对未知地区的外推能力；
5. 网页展示原始率 / 收缩率 / 校准后率，点击县区查看借用了哪些信息，
   可锁定确认项再重算，全部明细可导出。

纯 Python 标准库实现（无第三方依赖），CLI 与 Web 共用同一计算路径，结果可核查、可复现。

## 方法

### 1. 从抽样数据到县级统计量

每县样本为分层不等概率抽样（单元 j 含设计权重 w_j 与结果 x_j∈{0,1}）：

- 加权成功数 ỹ = Σ w_j x_j，权重和 W = Σ w_j，原始率 p̂ = ỹ / W
- Kish 有效样本量 n_eff = (Σw)² / Σw²，设计效应 deff = n / n_eff
- 连续性修正 p̃ = (ỹ + 0.5·w̄) / (W + w̄)（w̄ 为平均权重），使 0%/100% 极端率可取 logit
- z = logit(p̃)，s² = z 在 Binomial(round(n_eff), p̃) 下的**精确代入方差**
  （小样本下远优于 delta 近似：n_eff=1 时 delta 法虚报方差约 6 倍，会淹没真实县间差异）

### 2. 分层模型（收缩强度由数据估计）

```
z_i = x_i'β + u_i + e_i,   u_i ~ N(0, τ²),   e_i ~ N(0, s_i²)
```

- x_i = [1, 城镇化率, 老龄化指数, 收入指数]（地区特征）
- β 用加权最小二乘、τ² 用 DerSimonian–Laird 矩估计，两轮迭代，全程确定性
- 后验：μ_i = (1−B_i)·z_i + B_i·x_i'β̂，收缩权重 B_i = s_i²/(先验方差+s_i²)
- 先验方差 = τ̂² + x_i'(X'WX)⁻¹x_i（含系数不确定性）
- **零样本县**：μ_i = x_i'β̂，B=1，纯模型外推并在界面明确标记
- 率尺度变换：θ̂ = logistic(μ)，区间在 logit 尺度构造再变换，保证落在 (0,1)

### 3. 总量校准（估计与不确定性一起调整）

已知全市确认总量 T 与锁定集合 L（已确认项，率固定为确认值、方差为 0），求解

```
min  Σ_{自由县} (θ_i − m_i)² / V_i
s.t. Σ_i N_i θ_i = T,   0 ≤ θ_i ≤ 1,   锁定县 θ_i = 确认率
```

- KKT 解 θ_i(λ) = clip(m_i + λ·V_i·N_i, 0, 1)，λ 由总量方程二分求解（单调，200 次迭代收敛到机器精度）
- clip 自动激活非负/上限约束；贴边县方差归零
- 不确定性：自由县取等式约束下的条件协方差 Ṽ_i = V_i − (N_iV_i)² / Σ N_j²V_j，
  区间随点估计一起被总量信息收紧
- **不可行判定**（不暗改确认数据）：
  T − Σ_锁定 N_i·确认率 < 0 → 总量低于已确认项之和；
  T − Σ_锁定 N_i·确认率 > Σ_自由 N_i → 超出自由县承载上限

### 4. 整地区留出验证

5 折：每折整体留出一个地区，仅用其余地区重估 β、τ²，再预测留出县：

- 外推预测（仅 x'β̂，视同无样本）与收缩预测（再结合本县样本）
- 指标：90% 区间覆盖率（对模拟真值）、MAE、n_eff 加权 MAE（设计权重进入验证）
- 基线对照：原始率的加权 MAE

## 虚构数据与内置极端情形

`countyrate/data.py`（种子 20261125，完全可复现）：5 个地区 24 个县，
人口量级差 100 倍（2 千–25 万），并内置：

| 情形 | 县 | 说明 |
|---|---|---|
| 零样本 | 石门县、涟水县 | 估计完全依赖模型外推 |
| 小样本极端率 | 白岩县 n=1、荷风县 n=3 | 原始率 0%/100%，大幅收缩 |
| 已确认项 | 青云县等 6 县 | 行政确认计数，默认锁定 |
| 冲突总量 | 场景 `conflict` | 全市总量 < 已确认项之和 → 报告不可行 |
| 偏低总量 | 场景 `low` | 触发部分县的下界约束 |

`true_rate` 为模拟真值，仅用于验证与核查，估计流程不使用。

## 文件结构

```
countyrate/
  data.py       虚构数据生成（固定种子）
  linalg.py     极小线性代数（高斯消元、WLS）
  model.py      分层经验贝叶斯模型
  calibrate.py  总量校准（约束 + 不确定性联动 + 不可行报告）
  validate.py   整地区留出验证
  pipeline.py   端到端编排（CLI 与 Web 共用）
cli.py          命令行入口（导出 CSV/JSON 到 out/）
web/server.py   Web 服务（纯标准库）
web/static/     前端（原生 JS + SVG，无依赖）
tests/          35 个单元测试
```

## Web API

| 端点 | 说明 |
|---|---|
| `GET /api/state?scenario=X&locked=C01,C07` | 估计+校准结果（`locked=` 空串=全部解锁，缺省=默认锁定确认项） |
| `GET /api/validation` | 整地区留出验证明细 |
| `GET /api/export/estimates.csv?...` | 明细 CSV（与 CLI 同一代码路径） |
| `GET /api/export/summary.json?...` | 全部结果 JSON |

## 核查方式

1. `python3 -m unittest discover -s tests` —— 手算样例、约束满足、不可行判定、确定性
2. `python3 cli.py` 后对账 `out/estimates_baseline.csv`：校准后率 × 人口求和 = 全市总量
3. `out/units.csv` 为抽样单元级明细，可独立重算加权计数与有效样本量
4. 同一参数下 Web API 与 CLI 输出一致（共用 `countyrate.pipeline`）
